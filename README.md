# CSharp-Midterm

A mathematics-based game, where you have to answer progressively more difficult arithmetic questions to get a higher score. Of stretch goals; a western theme in gameplay animation, and added challenges to contribute to said score- presented in a top five run scoreboard. 

# Team
Grenadine Groves (BluCherry), Nolan Worrell (Codnex-Labs), Carson Kornstedt (Stormy-617)

# Minimum Viable Product
The minimum viable product of this project will satisfy the following criteria:
1. The user will input a given run’s username
2. There will be progressively more difficult mathematical problems that are shown on screen
3. The user will input numbers to answer the mathematical problems
4. After the user answers, a new mathematical problem will appear on screen
5. A user’s end score will be added to an external file (created upon first run and added to subsequently)
6. At the end of each run, the user’s score history will be displayed back to them with the top 5 scores
 
# Stretch Goals
1. A background animation of a guy running and shooting bandits upon the user answering a question correctly or getting attacked if the user answers incorrectly
2. A multiple life system
3. Background music
4. A timer for each question
5. ^^ speed included in (external file) scoreboard
6. Calculator the player can use for more difficult problems
7. Randomized mathematical equations based on a set difficulty
