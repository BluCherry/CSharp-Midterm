# CSharp-Midterm

A mathematics-based game, where you have to answer progressively more difficult arithmetic questions to get a higher score. Of stretch goals; a western theme in gameplay animation, and added challenges to contribute to said score- presented in a top five run scoreboard. 

# Team
Grenadine Groves (BluCherry), Nolan Worrell (Codnex-Labs), Carson Kornstedt (Stormy-617)

# Minimum Viable Product
The minimum viable product of this project will satisfy the following criteria:<br/>
The user will input a given run’s username<br/>
There will be progressively more difficult mathematical problems that are shown on screen<br/>
The user will input numbers to answer the mathematical problems<br/>
After the user answers, a new mathematical problem will appear on screen<br/>
A user’s end score will be added to an external file (created upon first run and added to subsequently)<br/>
At the end of each run, the user’s score history will be displayed back to them with the top 5 scores
